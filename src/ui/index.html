Conectar com a Blizzard

O Mercado lê os preços da Casa de Leilões direto da API oficial da Blizzard (não mexe no jogo, sem risco de ban). Cada pessoa usa a própria chave, que é grátis:

  1. Abra o site, entre com a conta Battle.net, aceite os termos e vá em API Access → Create Client.
  2. Nome: Lontrax AH · Redirect URL: http://localhost · Salvar.
  3. Copie o Client ID e o Client Secret e cole aqui embaixo.

A chave fica guardada com criptografia só neste computador. Sem chave, o app usa os preços da galera (atualizados de hora em hora pela Lontrax), então isto é opcional.
